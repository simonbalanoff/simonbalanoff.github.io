The problem

Understanding an unfamiliar object-oriented codebase means tracing types, members, and relationships across many source files. UML Visualizer brings that structure into a navigable diagram.

The tool recursively scans Java source directories and parses their contents without compiling the project being inspected.

Implementation

JavaParser extracts classes, abstract classes, interfaces, enums, records, and nested declarations. The viewer displays declared fields, methods, and constructors, including visibility and static or abstract styling.

Related types are grouped in a two-dimensional layout and connected using straight segments and right-angle bends. Selecting a type highlights its direct relationships and dims unrelated elements.

Interaction includes panning, zooming, fit-to-view, a minimap, and a member inspector. Diagram boxes preview up to four fields and four methods; the inspector contains the full parsed member list.

Usage & design decisions

Separate overview from detail: the diagram provides a compact structural view, while the inspector exposes a selected type’s members and connections.

Support desktop and command-line use: run a standalone JAR for the interactive viewer, or use the summary command to list parsed types without opening a window.

Allow embedding: another Java application can open the visualizer using its source-directory entry point.

Scope & limitations

The application visualizes relationships parsed from source, rather than runtime execution. It is designed for inspecting declared structure.

Records currently appear as classes. Choosing a specific source directory helps keep diagrams focused when a repository contains many Java files.
